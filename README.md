# Descargas — Chromis 1.5.4 con mejoras

**Última versión: 7 de noviembre de 2026** (cambian `chromispos.jar` y `admin.jar`)

| Para | Carpeta | Archivos |
|---|---|---|
| **Tiendas** | [Tiendas](Tiendas) | [chromispos.jar](Tiendas/chromispos.jar) · [admin.jar](Tiendas/admin.jar) · [restaurar.jar](Tiendas/restaurar.jar) |
| **Distribuidora** | [Distribuidora](Distribuidora) | [chromispos.jar](Distribuidora/chromispos.jar) · [admin.jar](Distribuidora/admin.jar) · [restaurar.jar](Distribuidora/restaurar.jar) |

Para descargar: abre el archivo y usa el botón de descarga (**Download raw file**,
la flecha hacia abajo a la derecha). Hay que tener la sesión de GitHub iniciada;
si el archivo baja con pocos bytes, no era el jar.

- `chromispos.jar` va en **todas las cajas**.
- `admin.jar` va en las PC donde se usa Chromis Admin.
- `restaurar.jar` es opcional: sirve para restaurar un respaldo (doble clic).

Cómo instalar: `INSTALAR.txt` dentro de cada carpeta. Huellas para comprobar
la descarga: `SHA256.txt`. Qué cambió en cada versión: [HISTORIAL.md](HISTORIAL.md).

### Novedades de esta versión

- **Buscador rápido de productos en la caja** (la lupa): encuentra mientras
  escribes, sin acentos, en plural, con errores ("Tal vez quisiste decir…"),
  por etiquetas y sinónimos. En Admin: etiquetas de búsqueda en Productos y
  la pantalla Sinónimos de búsqueda. El buscador anterior sigue en un botón.
- **Hora de cada producto en la venta** (solo cambia `chromispos.jar`).
- **Ventas en espera entre varias cajas**: ya no se duplican ni se pierden.
- **Ventas en espera borradas** en Admin: abierta en tal caja, perdida,
  borrada o cobrada; se pueden restaurar.
- **"Borrar todas" desactivado** (clic derecho o F10).
